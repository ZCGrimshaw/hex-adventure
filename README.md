# Hex Adventure

A pixel-art survival exploration game played on floating hexagons in space.
Reveal tiles one at a time, fight monsters in turn-based battles, craft tools, solve
lock-and-key puzzles, explore caves, defeat bosses and collect rare space gems.
How far can you get before you earn five skulls?

Play: https://zcgrimshaw.github.io/hex-adventure/

- Single file: `index.html`
- Runs autosave in the browser until the run ends
- Shared online Hall of Greats (ranked by tiles, then level, then gold)
